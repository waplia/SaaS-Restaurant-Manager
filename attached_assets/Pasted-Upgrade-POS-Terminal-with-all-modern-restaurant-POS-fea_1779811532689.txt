Upgrade POS Terminal with all modern restaurant POS features and proper flow.

POS should open as a full-screen page and include these features:

Main POS Flow:
1. Select outlet/counter/cashier shift
2. Select order type:
   - Dine-in
   - Takeaway
   - Delivery
   - QR Order
   - Reservation Order
3. For dine-in, select floor/table visually
4. Search/select customer or add new customer
5. Search menu items quickly
6. Browse categories/items with food images
7. Add items to cart
8. Customize items with variants, add-ons, modifiers, spice level, no onion, extra sauce, notes
9. Review cart/bill
10. Send KOT to kitchen
11. Hold/recall bill if needed
12. Apply discount/coupon/loyalty
13. Take payment
14. Print/share invoice
15. Complete order and update reports/inventory

Design:
