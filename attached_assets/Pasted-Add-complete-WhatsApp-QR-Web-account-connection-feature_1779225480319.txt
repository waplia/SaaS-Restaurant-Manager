Add complete WhatsApp QR Web account connection feature inside KhanaLagao provider/settings system.

Current requirement:
In restaurant settings/provider options, add an option where a restaurant can connect its own WhatsApp account using WhatsApp Web QR scan. After connecting, the platform should use that connected WhatsApp session for restaurant communication features where allowed.

Important:
- Do not break existing WhatsApp Cloud API provider if already built.
- Keep WhatsApp Cloud API and WhatsApp Web QR as separate provider options.
- WhatsApp Web QR should be optional and restaurant-controlled.
- Show clear warning that WhatsApp Web QR is unofficial/risk-based compared to official WhatsApp Cloud API.
- Do not send spam.
- Add limits, consent checks, logs, and safe sending rules.
- Do not use mock data.
- Build the complete flow with real connection status, QR generation, session storage, reconnect, disconnect, sending, logs, and failure handling.

Feature name:
WhatsApp Web QR Provider

Placement:
Restaurant Admin:
Settings → Providers → WhatsApp
or
Settings → Communication → WhatsApp

Super Admin:
System → Communication Providers
Feature Control → WhatsApp Web QR
Plan Limits → WhatsApp Web QR

Provider options:
1. WhatsApp Cloud API
2. WhatsApp Web QR
3. Custom WhatsApp Provider if already available
