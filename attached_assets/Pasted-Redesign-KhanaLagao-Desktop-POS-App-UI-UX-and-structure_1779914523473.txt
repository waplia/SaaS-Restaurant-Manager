Redesign KhanaLagao Desktop POS App UI/UX and structure into a premium modern restaurant desktop POS.

Goal:
The desktop app should look and feel like a real modern POS system, not a simple web dashboard. It should have a dedicated desktop-style layout with a large left menu, full POS workspace, hardware/printer controls, cashier workflow, QR orders, kitchen display, customer display, shift closing, and modern UI.

App name:
KhanaLagao POS

Platforms:
Windows desktop app
macOS desktop app

Important:
- Do not remove existing POS features.
- Do not change existing menu/order data.
- Do not use mock data.
- Use real backend APIs.
- Every button should work or show clear locked/configuration state.
- No dead buttons.
- No infinite loading.
- No raw ID inputs.
- Make it feel fast, professional, and cashier-friendly.
