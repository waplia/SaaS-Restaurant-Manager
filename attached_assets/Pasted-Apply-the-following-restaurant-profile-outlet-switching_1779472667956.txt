3. PRINT UPI QR ON BILL / INVOICE
==================================================

When restaurant has UPI QR enabled in profile, generate and print QR code on the customer bill/invoice.

UPI QR should use this format:

upi://pay?pa={upi_id}&pn={merchant_name}&am={bill_amount}&cu=INR&tn={bill_or_order_note}&tr={order_or_invoice_number}

QR should include:
- Restaurant UPI ID
- Merchant name
- Final payable amount
- Currency INR
- Invoice/order reference
- Payment note

Bill print layout should show:
- UPI QR code
- “Scan to Pay”
- UPI ID text if enabled
- Amount
- Invoice/order number

Add setting:
- Print QR only for unpaid bills
- Print QR for all bills
- Print QR only when payment method is UPI/online
- Hide QR after bill is marked paid optional

For KOT:
- Do not print UPI QR on KOT.
- UPI QR should print only on customer bill/invoice/receipt, not kitchen ticket.

For 58mm and 80mm printers:
- QR should be properly sized.
- QR should not cut off.
- Text should be readable.
- Add test print for UPI QR bill.

==================================================

2. Check outlet UPI settings.
3. If outlet UPI enabled, use outlet UPI ID.

5. Generate UPI QR using final payable amount.
6. Print QR on invoice/bill if enabled.
7. Do not print QR on KOT.

Add fallback:
- If UPI QR enabled but UPI ID missing, do not crash.
- Show warning to admin: “UPI QR is enabled but UPI ID is missing.”
