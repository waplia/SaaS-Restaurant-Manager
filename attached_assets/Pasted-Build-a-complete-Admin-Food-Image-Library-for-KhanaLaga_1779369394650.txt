Build a complete Admin Food Image Library for KhanaLagao.

Goal:
Super Admin should have a master image library of Indian food, drinks, desserts, snacks, breads, thali, sweets, fast food, beverages and restaurant items. Any restaurant can choose images from this library while creating menu items.

Important:
- Do not use copyrighted images directly from Google without license.
- Use only AI-generated images, royalty-free stock sources, uploaded images, or licensed/public image APIs.
- Do not add broken image URLs.
- Every image must be stored properly in our storage/CDN.
- Every image should be searchable and categorized.
- Restaurants should be able to select images easily from the library.
- Images should look realistic, clean, appetizing, and suitable for menu display.
- No fake/broken buttons.
- No raw image URL input only; allow upload, library select, and AI generate.

====================================================
4. IMAGE GENERATION / IMPORT FLOW
====================================================

Super Admin should have bulk image creation tool:

Super Admin → Media Library → Generate Food Images

Flow:
1. Select category/cuisine.
2. Select food items.
3. Select image style:
   - Realistic menu photo
   - Top view
   - Plate close-up
   - Restaurant table style
   - White background
   - Premium food photography
4. Select provider/model:
   - Gemini image model
   - OpenAI image model
   - Stable Diffusion/Cloudflare if configured
5. Generate images.
6. Review images.
7. Approve selected images.
8. Save to library with tags.

Prompt style for AI image generation:
“Create a realistic high-quality restaurant menu photo of {{food_item}}, Indian style, appetizing, clean plate presentation, natural lighting, no text, no watermark, suitable for digital menu image.”

Important:
- No text on food images.
- No watermark.
- No logos.
- No hands/people unless required.
- Food should look realistic and clean.
- Use square 1:1 images for menu items.
- Generate thumbnails.
