Build complete Email Template Center and WhatsApp Cloud Template Library for KhanaLagao.

Goal:
KhanaLagao should have a complete template system for:
1. Super Admin platform emails
2. Restaurant customer emails
3. WhatsApp Cloud API templates
4. WhatsApp template sync/edit/submit flow
5. Restaurant activity notifications on WhatsApp
6. Marketing, utility, and authentication templates
7. Variables, preview, testing, approval status, logs, and usage tracking

Important:
- Do not break existing email, WhatsApp, SMS, web push, campaign, provider, or notification systems.
- Super Admin owns provider configuration and global templates.
- Restaurant admin should not manage provider API keys or WhatsApp Cloud API tokens.
- Restaurant admin can only use templates allowed by Super Admin and plan.
- Restaurant can customize allowed templates if permitted.
- WhatsApp templates must support Meta Cloud API format.
- Support template categories:
  - AUTHENTICATION
  - UTILITY
  - MARKETING
- Use real database, real APIs, real provider status, real Meta sync.
- No mock success.
- No fake template approval.
- No infinite loading.
- Every template must support variables/placeholders.
- Every message sent must be logged.
