Build KhanaLagao Desktop POS App using Electron for Windows and macOS.

Goal:
Create a production-ready desktop POS app for KhanaLagao restaurants. The desktop app should work like a real restaurant cashier POS system with full-screen POS, printer support, sound alerts, offline cart safety, KOT printing, payment integrations, table management, and secure login.

Important:
- Use Electron for desktop app.
- Build for Windows .exe installer.
- Build for macOS .dmg installer.
- Keep existing web dashboard, backend, mobile app, and POS APIs unchanged.
- Reuse existing POS UI where possible but optimize it for desktop.
- Do not use mock data.
- Desktop app must connect to real KhanaLagao backend APIs.
- App must support real restaurant login, role permissions, outlet/counter selection, and cashier shift.
- No dead buttons.
- No infinite loading.
- No raw ID input.
- Desktop app should feel like a fast native POS, not a browser window.

App Name:
KhanaLagao POS

Desktop Package Names:
Windows App Name: KhanaLagao POS
macOS App Name: KhanaLagao POS
