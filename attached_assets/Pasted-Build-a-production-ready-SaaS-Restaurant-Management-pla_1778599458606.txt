Build a production-ready SaaS Restaurant Management platform inspired by TableTrack. The app should support multi-restaurant tenants, POS, QR ordering, kitchen management, waiter management, subscriptions, analytics, and customer ordering.

Tech Stack:

* Frontend: Next.js 15 + TypeScript + TailwindCSS + shadcn/ui
* Mobile App: React Native Expo
* Backend: Node.js + Express or NestJS
* Database: PostgreSQL with Prisma ORM
* Authentication: JWT + Role Based Access
* Realtime: Socket.io
* Storage: AWS S3 compatible
* Payments: Razorpay + Stripe
* Deployment ready with Docker
* Clean scalable architecture

Main Goal:
Create a modern SaaS restaurant platform where multiple restaurants can register and manage their operations from separate dashboards.
