## Loyalty Module for TableTrack

The Loyalty Module empowers restaurant owners to create and manage customer loyalty programs directly within TableTrack. Reward your customers with points for their purchases, automate point redemptions, and encourage repeat visits—all seamlessly integrated with your restaurant’s TableTrack dashboard.

### Technical Specifications

- Native integration with Laravel + Livewire
- Elegant, intuitive user interface (Tailwind 3)
- Customizable loyalty rules, earning rates, and redemption policies
- Compatible with all modern web browsers

### Requirements

- TableTrack base application (version 1.2.56 or later)

### Setup

Setting up the Loyalty Module is simple—no coding skills required. Please review the included documentation for step-by-step installation and configuration, or contact our support team for assistance.
