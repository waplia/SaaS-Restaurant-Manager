Redesign the KhanaLagao Restaurant Mobile App into a modern, easy-to-use, fully functional restaurant operations app.

Important correction:
The center highlighted button in the bottom navigation should NOT be Scan. It should be “New Order”.

The app should feel simple and modern like PhonePe/Paytm style home screen: big rounded action cards, easy access, clean icons, highlighted main action, and fast daily-use experience. But this app is for restaurant owners/staff, not customers.

Current issues:
- App UI is too basic.
- Features feel like a simple list.
- It is not easy to use.
- New Order should be the main center action.
- Items should be searchable while creating order.
- Menu/category/item flow should be fast like a restaurant POS/mobile ordering app.
- All screens should work with real data.
- No mock data.
- No blank screens.
- No infinite loading.

Brand:
KhanaLagao

Theme:
Modern restaurant operations app
Orange + warm white + dark premium UI
Rounded cards
Large touch buttons
Simple navigation
Fast workflows
Real-time order and kitchen status

====================================================
1. APP MAIN NAVIGATION
====================================================

Use bottom navigation:

1. Home
2. Orders
3. New Order
4. Alerts
5. More

Important:
- “New Order” should be the center highlighted button.
- It should be a large round/orange gradient button slightly raised above bottom nav.
- Icon: plus/order/bill icon.
- Label: New Order
- This should be the most important action in the app.

Bottom nav behavior:
- Home = restaurant overview
- Orders = live orders
- New Order = create new order quickly
- Alerts = urgent notifications/approvals
- More = all modules/settings

Do not make Scan the center button.
Scan should be available inside New Order or More as a secondary tool.

3. ITEM SEARCH IN NEW ORDER
====================================================

Item search is mandatory.

In New Order screen, add:
- Search bar at top: “Search items, categories, add-ons…”
- Category chips
- Veg/non-veg filter
- Bestseller filter
- Recent items
- Popular items
- Frequently ordered items
- Out-of-stock hidden/disabled
- Item image thumbnails
- Add button
- Customize button if add-ons/modifiers exist

Search should work by:
- Item name
- Category
- SKU/code if available
- Tags
- Add-on name optionally

Search UX:
- Results should appear instantly.
- Highlight matching item.
- Show item image, name, price, availability.
- If no item found, show helpful empty state.
- Add “Create new item” shortcut only for owner/admin if permission allows.
