Add a complete “Download Apps” section in KhanaLagao dashboard and Super Admin.

Goal:
Restaurant users should easily download KhanaLagao apps from their dashboard:
- Android app
- iOS app
- Windows desktop POS app
- macOS desktop POS app
- Optional web/PWA install guide

Super Admin should be able to manage these app download links, upload files, versions, release notes, and visibility.

Do not use mock links. If link/file is not added by Super Admin, show “Coming soon / Not available yet” clearly.

====================================================
1. RESTAURANT DASHBOARD ENTRY
====================================================

Add a card/button on restaurant dashboard:

Title:
Download Apps

Subtitle:
Install KhanaLagao on mobile, desktop, and POS devices.

Button:
Open Downloads

Also add in sidebar/menu:
Settings → Download Apps
or
Help → Download Apps

====================================================
3. INSTALLATION GUIDES
====================================================

Add guide sections/modal for each platform.

Android guide:
- Download APK or open Play Store.
- Allow install from unknown sources if APK.
- Install app.
- Login with restaurant account.

iOS guide:
- Open App Store/TestFlight.
- Install app.
- Login with restaurant account.

Windows guide:
- Download .exe installer.
- Run installer.
- Allow Windows Defender if prompted.
- Login and select outlet/counter.
- Setup printer from Hardware page.

macOS guide:
- Download .dmg.
- Drag app to Applications.
- If blocked, allow from Privacy & Security.
- Login and setup printer.

PWA guide:
- Open web app in Chrome/Edge/Safari.
- Click Install/Add to Home Screen.
- Login and use.

====================================================
4. SUPER ADMIN APP DOWNLOAD MANAGER
====================================================

Create Super Admin page:

Super Admin → App Downloads

Super Admin can manage:

For each app/platform:
- Platform: Android / iOS / Windows / macOS / Web/PWA
- App name
- Version
- Build number
- Release date
- Status: active/inactive/coming soon/deprecated
- Download type:
  - External link
  - Uploaded file
  - Store link
- Upload file:
  - APK
  - AAB optional internal
  - EXE
  - DMG
  - ZIP
- External URL:
  - Play Store link
  - App Store link
  - TestFlight link
  - Direct download URL
- File size
- Minimum OS version
- Release notes
- Installation guide
- Force update yes/no
- Recommended update yes/no
- Visible to restaurants yes/no
- Visible by plan yes/no
- Visible by restaurant override optional

Super Admin actions:
- Add app download
- Edit
- Upload new version
- Archive old version
- Mark latest
- Preview restaurant download page
- Copy link
- Delete/archive

====================================================

Restaurant users:
- Can view/download apps if allowed.

- Can upload/manage app download links.

Do not allow restaurant admin to change global app download files or links.
