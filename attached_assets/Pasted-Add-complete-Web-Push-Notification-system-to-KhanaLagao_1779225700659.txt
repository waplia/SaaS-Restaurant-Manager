Add complete Web Push Notification system to KhanaLagao with Super Admin provider control, restaurant enable/disable, marketing campaigns, rich images, subscriber counts, consent, logs, analytics, and full platform integration.

Important:
- All provider configuration must be in Super Admin only.
- Restaurant admin must not enter or manage VAPID keys, Firebase keys, OneSignal keys, API keys, or any provider secrets.
- Restaurant admin should only enable/disable allowed notification features, manage templates/campaigns, view subscribers, view logs, and use limits allowed by plan.
- Do not break existing notification system.
- Do not send marketing notifications unless restaurant enables it and customer/browser subscriber has opted in.
- Use real browser push notification technology, not mock UI.
- Add full support for image notifications, especially marketing campaign images.
- Add total subscriber counts and opt-in analytics.
- Add logs, consent, limits, templates, campaign analytics, and Super Admin controls.
- Make it work across QR menu, online ordering, customer pages, restaurant admin, Super Admin, and PWA where supported.

Feature name:
Web Push Notifications / Browser Notifications

Brand:
KhanaLagao

4. CUSTOMER OPT-IN FLOW
====================================================

Build proper customer/browser opt-in.

Where opt-in can appear:
- QR menu customer page
- Online ordering page
- Customer loyalty/profile page
- Review page after order
- Direct ordering website
- Customer web app
- PWA install flow if supported

Use soft prompt before browser permission.

For order updates:
Text:
“Get notified when your order is ready?”

Buttons:
- Allow Updates
- Not Now

For marketing:
Text:
“Get special offers from this restaurant?”

Buttons:
- Allow Offers
- No Thanks

Flow:
1. Customer sees custom soft prompt.
2. If user clicks Allow, request browser notification permission.
3. If browser permission granted, save subscription.
4. Store order update opt-in and/or marketing opt-in.
5. If denied, store denied/blocked state.
6. If unsupported browser, show graceful message.

Do not force notification permission immediately.
Do not ask repeatedly after user says Not Now.
Add cooldown for re-prompting.
