Update my restaurant SaaS sidebar, navigation structure, module grouping, and feature visibility.

Important:
The platform is already built with many features. Do not rebuild existing features. Do not remove working features. Only reorganize the sidebar/navigation and module structure professionally so the platform looks world-class, clean, scalable, and easy to use.

Goal:
Arrange all features in the best SaaS restaurant operating system structure. Keep daily-use features in the main sidebar. Move advanced industry-specific features into optional modules/add-ons. Move configuration features into Settings. Keep important growth and AI features visible as main modules.

The platform should feel like:
“Restaurant Operating System + Growth Cloud + Finance + Khana AI”
